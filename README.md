# Unified Mentor Internship

Practice projects built during the Unified Mentor internship, focused on core front-end fundamentals using plain HTML, CSS, and JavaScript.

## Projects

### Calculator

A basic calculator supporting standard arithmetic operations, built with HTML, CSS, and JavaScript.

### Countdown Timer

A countdown timer app that counts down to a target time, built with HTML, CSS, and JavaScript.

## Tech Stack

HTML, CSS, and vanilla JavaScript, with no external frameworks or libraries.

## Getting Started

Each project lives in its own folder. Open the `index.html` file inside a project folder directly in your browser to run it.
